## Pasos para ejecutar el proyecto
1. Clonar este repositorio en la máquina local.
2. Abrir la terminal en la raíz del proyecto y ejecutar `npm install`.
3. Crear un archivo `.env` basándose en el archivo `.env.example` incluido, y llenarlo con las credenciales de Firebase.
4. Ejecutar el comando `npx expo start -c`.
5. Escanear el código QR con Expo Go en el celular o presionar 'a' para abrir el emulador de Android.
